Enterprise Tag Governance Framework & Compliance Dashboard

Data assets across a 5,600+ object Snowflake estate were inconsistently classified and documented, making data hard to discover, govern, and trust — a blocker for reliable analytics and AI use cases. There was no single, real-time view of tagging compliance across the estate's 118 schemas.

What I did

  • Embedded governance checks into dbt pipelines and Infrastructure-as-Code so standards are enforced automatically at deploy time.

The result

Data Governance & Analytics · Automated Market Data Pipeline

Self-Healing Financial Market Data Lake & Audit Framework

The problem

Financial derivatives data disappears from broker APIs once contracts expire, while manual downloads often suffer from missing trading days, inconsistent schemas, redundant columns, and zero audit visibility — making historical datasets unreliable for analytics and backtesting.

Challenges faced & solved

  • Standardizing Data Quality & Schemas: Enforced strict, clean column standards across Indices, NIFTY 50 Stocks, and Commodities — eliminating redundant fields and enriching every record with accurate exchange-calendar DTE metrics.
  • Preventing Silent Data Gaps: Built an automated audit calendar (audit_calendar.csv), daily completeness checks (verifying 375/375 trading-minute candles), and instant Telegram alerts so any missing day or error is caught immediately before contracts expire.
  • Running Reliably on Minimal Cloud Resources: Organized storage into clean lifecycle layers (incoming ➔ archive ➔ processed) using compressed Parquet files and memory-safe DuckDB merges to run smoothly on a free 1 GB RAM cloud VM.

What I achieved

  • 600K+ clean, standardized records captured automatically every day
  • ~90% smaller storage footprint using compressed Parquet archives
  • 100% auditability with daily completeness checks and gap alerts
